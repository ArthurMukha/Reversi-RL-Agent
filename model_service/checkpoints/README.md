# Веса моделей

Отобранные версии агента. Лежат в git намеренно — файл весит ~650 КБ, зато
игра против модели работает сразу после клонирования репозитория.

Сюда кладём **только отобранные** модели, а не каждую итерацию обучения:
git хранит все версии навсегда.

## Формат файла

```python
{
    "state_dict": ...,                                  # веса
    "arch": {"channels": 64, "n_res_blocks": 2},        # kwargs PolicyNetwork
    "meta": {...},                                      # происхождение и метрики
}
```

`arch` дублирует то, что и так выводится из форм тензоров — при загрузке одно
сверяется с другим. `meta` вывести неоткуда, она пишется руками при сохранении.

Загружать через `model_service/checkpoint.py`, проверить всё, что лежит в папке:

```bash
python -m model_service.checkpoint
```

## Модели

Обе — `PolicyNetwork(channels=64, n_res_blocks=2)`, около 162 тысяч параметров.
Обучены self-play с MCTS (100 симуляций, `c_puct=1.5`, seed 116), отбор
кандидатов через арену на 50 партиях.

| model_id | итерация | винрейт на арене | против | примечание |
|---|---|---|---|---|
| `iter13-wr72` | 13 | 0.72 | `iter12-wr57` | лучшая на сегодня |
| `iter6-wr60`  | 6  | 0.60 | `iter5-wr53`  | последняя до зависания Kaggle |

Обучение идёт на Kaggle, оттуда скачивается `state_dict`. Обёртку в формат
выше делает сохранение внутри `Learner` — см. `docs/model-integration-plan.md`,
пункт 0.1д.
