# Reversi RL Agent

Игра **Реверси (Отелло)** в терминале на Python + обучение игрового ИИ
методами обучения с подкреплением (Reinforcement Learning).

Цель проекта — не просто сделать играбельную версию Реверси, а обучить
нейросетевого агента играть на приличном уровне и дать возможность
сразиться с ним прямо в терминале.

## Возможности

- Полноценная логика Реверси: расчёт допустимых ходов, переворот фишек, подсчёт очков.
- Управление с клавиатуры (стрелки + Enter), рендеринг доски через `curses`.
- RL-агент на **PyTorch**: свёрточная policy-сеть (`Conv2d` + `Linear`),
  обучение через взаимодействие со средой (policy-gradient / DQN).

## Стек

- **Python 3**
- **PyTorch** — обучение агента
- **curses** — терминальный интерфейс
- **NumPy / Matplotlib** — обработка данных и визуализация обучения

## Структура

```
reversi_rl_agent/
├── main.py        # точка входа, игровой цикл
├── board.py       # состояние доски и её инициализация
├── config.py      # константы (фишки, размеры, направления)
├── rules.py       # правила: допустимые ходы, подсчёт очков
├── input.py       # применение хода и переворот фишек
├── renderer.py    # отрисовка доски и счёта в терминале
└── model/
    └── training_1.ipynb   # эксперименты по обучению RL-агента
```

## Запуск

```bash
python main.py
```

Управление: **стрелки** — перемещение курсора, **Enter** — сделать ход,
**r** — новая игра, **q** — выход.
